# PyStart — интерактивный учебник Python

Современный русскоязычный учебник для начинающих. Внутри — 18 тем, примеры кода с объяснениями, жизненные аналогии, практические задания и короткие тесты.

## Запуск

Проект не требует сборки и установки зависимостей:

1. Скачай или клонируй репозиторий.
2. Открой `index.html` в браузере.
3. Для публикации включи **Settings → Pages → Deploy from a branch → main / (root)**.

Интерфейс использует Google Fonts и Lucide Icons через CDN. При отсутствии интернета основной учебник продолжит работать, но внешние шрифты и иконки могут не загрузиться.

## Структура

- `index.html` — главная страница, каталог уроков и оболочка учебника.
- `style.css` — адаптивный дизайн, тёмная тема, жёлтые и зелёные акценты.
- `app.js` — программа курса, теория, примеры, задания, тесты и сохранение прогресса.

1. Знакомство с Python
2. `print()` и `input()`
3. Переменные
4. Типы данных и преобразование
5. Операторы и вычисления
6. Строки и форматирование
7. Списки
8. Кортежи, множества и словари
9. Условия `if / elif / else`
10. Циклы `for / while`
11. Функции
12. Ошибки и `try / except`
13. Работа с файлами
14. Модули и библиотеки
15. Алгоритмы и поиск
16. Классы и объекты
17. Наследование и принципы ООП
18. Итоговый проект

## Возможности

- Адаптивная вёрстка для компьютера, планшета и телефона.
- Тёмный интерфейс с чёрной основой, жёлтыми и зелёными акцентами.
- Переключение на светлую тему.
- Поиск по урокам и фильтры по прогрессу.
- Примеры кода с кнопкой копирования.
- Практические задания и тест в каждом уроке.
- Прогресс хранится локально в браузере через `localStorage` и не синхронизируется между устройствами.

## Примечание

Это учебный фронтенд-проект без серверной части и аккаунтов. Прогресс хранится в текущем браузере. Примеры кода нужно запускать в установленном Python или в выбранной онлайн-среде.
